# Nbody-Sim
A simulation that calculates the forces from each body onto another till a N amount of Bodies. Simualting their interaction with one and another
## Dependencies 
  Vypthon - ***pip install vpython***
## Explination 🧐
  Lets say you put spheres with gravity simulating stars in a box.How would they react? What would happen to them?.To answer this in my       freetime being jobless 😎 I made an n body simulation.
  
  This simulation works by calculating the pull and push of each star on every combination.For example if there are 3 bodies (S1, S2 ,S3) and they were in a triangle for example (Figure 1).Here the blue arrow and red arrow pulling upon n1 act as a “slingshot” essentially catapulting the stars before the red slightly moves it back.This causes rapid chaotic movement between the bodies when they all start moving.As we add more bodies the arrows increase exponentially.Here the stars have equal mass but in real cases they would not and thus this would cause some stars to be catapulted due their size allowing for rapid distances with less energy and the middle ones would form a core of sorts with the higher mass bodies remaining there.This is seen in the simulation (In this case 100 bodies and rate =300 and 100 seconds) in figure 2.The lighter bodies as seen get slingshooted away and due to the moving gravitational pull they remain in a slight orbit but not significant enough for any action but an influence remains.
